# Outubro Rosa Speech Bubbles

Printable speech-bubble signs created for Breast Cancer Awareness Month campaigns (Outubro Rosa).

## 🇧🇷 Português

### Sobre o projeto

Minha esposa precisava de algumas plaquinhas com balões de texto para uma sessão de fotos da campanha Outubro Rosa na escola. Como esse tipo de material tem sido bastante utilizado em campanhas e publicações nas redes sociais, ela procurou algumas opções prontas para impressão.

Encontramos diversas artes disponíveis na internet, mas apenas em serviços pagos. Como alternativa, resolvi criar minhas próprias versões para contribuir com essa campanha de conscientização tão importante e disponibilizá-las gratuitamente para quem precisar.

### Conteúdo do repositório

- Arquivos-fonte em **Inkscape** (`.svg`)
- Arquivos do **GIMP** (`.xcf`)
- Versões em **PDF** prontas para impressão

### Edição

Para editar as artes, os arquivos do Inkscape são suficientes.

O GIMP foi utilizado apenas na criação da moldura dos balões, baseada em uma textura repetitiva que encontrei em formato PNG. Infelizmente, não consegui localizar a fonte original desse arquivo para fornecer os devidos créditos. Posteriormente, a moldura foi vetorizada no Inkscape.

### Observações

Sou apenas um usuário eventual tanto do GIMP quanto do Inkscape, então peço desculpas por eventuais imperfeições nos arquivos.

Espero que este material seja útil e ajude a fortalecer as ações de conscientização sobre a prevenção e o diagnóstico precoce do câncer de mama.

## 🇺🇸 English

### About this project

My wife needed some speech-bubble signs for a photo session as part of her school's Breast Cancer Awareness Month campaign (known in Brazil as *Outubro Rosa*). Since this type of material has become quite popular in awareness campaigns and social media posts, she started looking for ready-to-print options.

We found several designs online, but all of them were available only through paid services. As an alternative, I decided to create my own versions to contribute to this important awareness campaign and make them freely available to anyone who might find them useful.

### Repository contents

- **Inkscape** source files (`.svg`)
- **GIMP** files (`.xcf`)
- Print-ready **PDF** files

### Editing

If you want to edit the artwork, the Inkscape files are all you need.

GIMP was used only to create the speech-bubble border, based on a repeating texture I found in PNG format. Unfortunately, I was unable to locate the original source of that file to provide proper attribution. The border was later vectorized in Inkscape.

### Notes

I am only an occasional user of both GIMP and Inkscape, so please forgive any imperfections you may find in the files.

I hope this material proves useful and helps support awareness efforts focused on the prevention and early detection of breast cancer.
